# Back Reset

Guided back-release stretches and a stand / sit / move desk timer.

- **Stretches**: Back Release (twice a day), McGill Big 3 (once a day), Hips & Mid-Back
  (phase 2). Timed holds, voice cues, count-in pips, and the screen stays on.
- **Desk timer**: cycles Stand → Sit → Move (25 / 15 / 5 by default) with a short beep-beep
  at each change - even with the phone asleep, as long as the page is left open.

Live: https://philoutram.github.io/back-reset/

Not medical advice - built from a personal recovery plan.
